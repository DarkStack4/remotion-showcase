# Plano — Animação Kinetic (60s)

Objetivo: vídeo de 60s, 1920x1080, 30fps, dinâmico, coerente, cortes rápidos, render via GitHub Actions.

## Cenas (1800 frames)
1. 0-120 Intro cinética
2. 120-300 Partículas
3. 300-480 Grid morfando
4. 480-660 Tipografia
5. 660-840 Equalizer
6. 840-1020 Espiral
7. 1020-1200 Contagem
8. 1200-1380 Mosaico
9. 1380-1560 Transição de cor
10. 1560-1740 Assinatura
11. 1740-1800 Outro

## Componentes
Kinetic, Transition, ParticleField, KineticText, Equalizer, Spiral, ProgressRail.

## Performance
96 partículas máx, transforms/opacity, concurrency 2.

## Render
Workflow render.yml com id Kinetic, artefato kinetic.mp4, abrir ao final.
